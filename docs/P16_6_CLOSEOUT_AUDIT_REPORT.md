## 5. Environment Limitations

The P16.6-E test failure classification is **ENVIRONMENT LIMITATION**. The evidence is specific: Supertest throws in `Test.serverAddress()` while `app.address()` is null; a separate Express listener probe fails with `listen EPERM`; and Redis socket access also fails with `EPERM`. These failures occur before a request reaches the affected application route or assertion. The 64 failures must not be treated as 64 product defects, but 168 passing tests do not make the entire suite pass. Earlier P16.6-B reports that rerunning with local socket access passed its full suite; that historical run does not convert the P16.6-E run to PASS.

The missing live empty/multiple-page data and safely reproducible API error conditions are data/runtime constraints. They are not UI defects and do not authorize seeding or disrupting shared services.
